# saba-dy — интернет-магазин натурального мыла

Полноценный магазин: витрина, корзина, оформление заказа с оплатой через ЮKassa, серверная часть и панель администратора.

**Сайт:** https://www.saba-dy.ru/

## Что внутри
| Папка | Что это |
|---|---|
| `/` (`index.html`, `checkout.html`, `js/`, `css/`) | витрина магазина: каталог, корзина, оформление заказа, юридические страницы |
| `server/` | API на Node.js + Express, база SQLite, загрузка фото товаров (multer), интеграция с ЮKassa (платежи, webhook) |
| `admin-panel/` | исходники админки на React + TypeScript + Vite + Tailwind: товары, заказы, настройки |
| `admin/` | собранная админка, которую отдаёт сервер |
| `premium-redesign/` | редизайн витрины (статический сайт, выложен на Netlify) |
| `nginx.conf`, `nginx-https.example.conf` | конфигурация для продакшн-сервера |

## Запуск локально
```bash
cd server
cp .env.example .env   # заполнить свои значения
npm install
npm start              # http://127.0.0.1:8000
```
Админка: `cd admin-panel && npm install && npm run dev`.

Подробная инструкция по установке — в `ПРОВЕРКА-И-УСТАНОВКА.md`. Ключи и пароли в репозитории не хранятся, они задаются через `server/.env`.
